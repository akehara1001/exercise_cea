# 校准第七轮的接受规则（运行前确定）

确定日期：2026-10-22（用户指示）。本文件在第七轮校准运行之前单独提交到 git；第七轮的校准与 bootstrap 均在此提交之后运行。

## 规则

- (a)、(b) 及其例外规则不变（见 `docs/acceptance_rule_round6.md`）：
  - (a) 各臂第 1 至第 5 年每个整年时点，模型 OS 落在重建 KM 的逐点 95% 置信区间内；不达标时，只在同时满足 (i) 每个区间外的点超出 ≤ 0.3 个百分点、(ii) 全部 10 个点落在 Bonferroni 校正后的逐点 99.5% 区间内时接受。
  - (b) 模型的 5 年 RMST 两臂差落在 KM 两臂差的 bootstrap 95% 区间内。
- 新增 (c)：模型在 7 年时的 OS 和 EFS，各臂都落在 KEYNOTE-522 最终分析（J Clin Oncol 2026;44(16_suppl):507，截点 2025-10-14）报告的 95% 置信区间内（共 4 个值；数值见 `data/kn522_final_7y.csv`）。
- 按 pCR 分层的 7 年 OS 没有报告置信区间，只报告差值，不作门槛。
- 不满足就停下报告，不自行增加结构。

## 理由（写入门槛修改记录）

最终分析提供了 7 年的成熟数据，两臂 OS 差从 5 年时的 4.9 个百分点扩大到 7.9 个百分点。

## 说明

- 7 年 EFS 由步骤 4 的 EFS 模型决定，不受校准量（术前进展后与远处复发后的死亡、k）影响；(c) 中 EFS 的两个值在校准前后不变。
- 术前进展约束与 k 的边界照常报告，不作停止条件（与第六轮相同）。
