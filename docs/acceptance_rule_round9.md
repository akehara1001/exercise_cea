# 校准第九轮的接受规则（运行前确定）

确定日期：2026-10-23（用户指示）。本文件在第九轮校准运行之前单独提交到 git；第九轮的校准在此提交之后运行。第九轮只做点估计，bootstrap 交给 Longleaf。

## 规则

与第八轮相同（见 `docs/acceptance_rule_round8.md`、`docs/acceptance_rule_round7.md`）：

- (a) 各臂第 1 至第 5 年每个整年时点，模型 OS 落在重建 KM 的逐点 95% 置信区间内；不达标时，只在同时满足 (i) 每个区间外的点超出 ≤ 0.3 个百分点、(ii) 全部 10 个点落在 Bonferroni 校正后的逐点 99.5% 区间内时接受。
- (b) 模型的 5 年 RMST 两臂差落在 KM 两臂差的 bootstrap 95% 区间内。
- (c) 模型在 7 年时的 OS 和 EFS，各臂都落在 KEYNOTE-522 最终分析报告的 95% 置信区间内（共 4 个值；`data/kn522_final_7y.csv`）。
- 不满足就停下报告，不自行增加结构。
